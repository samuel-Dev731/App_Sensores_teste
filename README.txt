Como compilar este projeto no Android Studio:
1. Descompacte este arquivo ZIP.
2. Abra o Android Studio e selecione 'Open' na pasta descompactada.
3. Aguarde o Gradle terminar a sincronizacao.
4. No menu superior, clique em Build > Build Bundle(s) / APK(s) > Build APK(s).
5. O arquivo .apk final sera gerado automaticamente.
